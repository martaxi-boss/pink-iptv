# PINK IPTV Brand System

Status: APPROVED AS ANDROID SHELL 002 BASELINE.

The palette and visual direction below are approved for the Android Shell 002 implementation. Final distribution/store artwork and production asset certification remain pending.

## Identity

Name: PINK IPTV
Tone: premium, modern, simple, technical, friendly.
Logo concept: an original abstract P + play/streaming mark.

## Core colors

- Pink Primary: #FF2D8D
- Magenta Deep: #D4146C
- Pink Soft: #FF8FC1
- Ink: #141722
- Surface Dark: #1C2030
- Surface Raised: #252A3A
- Blush: #FDF7FB
- White: #FFFFFF

## Usage

Dark app surfaces with strong pink focus/selection states.
Avoid excessive gradients inside dense channel lists.
Reserve bright magenta for primary actions, selected items, live badges and focus.

## Typography

Use an open/system sans-serif family with excellent Android/Windows availability.
Do not bundle unlicensed fonts.
Favor readable medium weights on TV.

## Iconography

Create or use properly licensed generic system icons.
No copied Smarters icons/assets.
