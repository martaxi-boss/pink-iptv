# PINK Backend

Preferred baseline:
- Python 3
- FastAPI
- PostgreSQL
- SQLAlchemy/Alembic or equivalent audited migration stack
- pytest

Responsibilities:
- Mega OTT adapter
- username -> subscription mapping
- dns_link resolution
- Xtream credential validation orchestration
- short-lived client configuration/session
- app config
- VPN enrollment/control plane later

Non-responsibility:
- never relay IPTV video streams.

No implementation begins until Supervisor Order 001.
